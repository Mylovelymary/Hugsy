# Хагси

Тёплый сайт-помощник для тех, кому тяжело: понять, с чем нужна помощь, и получить под это
рабочие инструменты. Без регистрации, без диагнозов, без оценок.

- **Анкета** — 16 вопросов, на выходе направления и что с ними делать
- **Таблицы** — дневник чувств и любые свои таблицы, отметка настроения в два касания
- **Рутина дня** — дробление задач, таймер фокуса, подсказки на случай «не могу начать»
- **Аптечка** — 26 упражнений при панике и тревоге
- **Близким** — что говорить и чего не говорить, если тяжело не тебе
- **Помощь** — бесплатные линии и сервисы подбора специалиста
- **Темы** — пять оформлений, 14 узоров, своя картинка на фон

Записи хранятся только в браузере на устройстве человека. Сервера нет, аккаунтов нет,
аналитики нет.

## Как запустить

```bash
python3 tools/devserver.py 8000
```

Открыть http://localhost:8000. Это обычный статический сервер, но он запрещает браузеру
кешировать файлы — иначе при разработке правки CSS и JS не видно.

Можно просто открыть `index.html` двойным кликом: сайт работает и так, только без офлайн-кеша.

## Из чего сделано

HTML, CSS и JavaScript. Ни сборки, ни зависимостей, ни единого запроса наружу —
шрифты и картинки лежат рядом. Главная страница весит 222 КБ и открывается за 43 мс,
после первого захода сайт работает без интернета.

```
index / quiz / tracker / routine / resources / close / themes   страницы
panic/                   раздел «Аптечка»: паника и тревога
assets/css, assets/js    стили и логика
assets/fonts, assets/img шрифты и маскоты
data/                    контент: вопросы, упражнения, ссылки, узоры, иконки
tools/devserver.py       локальный сервер для разработки
sw.js                    офлайн-кеш
```

Контент отделён от кода: вопросы анкеты, упражнения и ссылки лежат в `data/` и правятся
без знания программирования.
